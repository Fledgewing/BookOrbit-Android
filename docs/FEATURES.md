## Scope and interpretation

- Source audit, no physical device testing; Android permissions/vendor behaviour can restrict helpers.
- Absence claims are based on native settings inventories and build gates; a similarly named native reader feature is not counted as an Orbify addition.
- No touch requirement for parity: buttons may expose the same outcome. Lack of touch alone does not justify missing controls.
- Fonts, stock Home/catalog and annotations are native integrations; only Orbify adapters, lifecycle hooks and explicit cuts are scored, not all upstream reader capabilities.
- X3 upstream cuts also remove Nearby, mDNS, plugin hub and asset downloads; English-only built-in UI in platformio.local.ini. These are constraints on inherited capabilities, not Orbify features.
- Server quirks motivating overlays: final progress alone may not finish a book; send-time stale pushes can win; metadata writes change file hashes. See docs/server-contract.md sections linked in the matrix notes.
