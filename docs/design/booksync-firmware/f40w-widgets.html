BookSync · 0.12 firmware · F40w

A place for every part of reading

ALL SCENES NEED APPROVAL

Distinct widget proposals adapted from Home revision 16 and the Android card renderers. Covers, reading charts and typography keep their visual roles; the firmware views use black and white. X4 Classic has visible button focus. X3 uses designed text summaries, tabular values and clear actions.

Ordered by the coordinator’s Android 0.11 usage priority: Continue and Also reading, Recently added, Book list, Stats, then the rest. This is an editorial ordering, not new usage telemetry. Every widget appears at one main size on all three profiles, with one compact strip for empty, off, unsupported, stale and oversize states.

Sources and Android differences · Approved firmware gallery · Android revision-16 gallery. All content is invented. No firmware, new defaults or approval is implied.
