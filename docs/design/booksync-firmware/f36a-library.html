Library and lists

BookSync firmware proposal for X4 Pro touch, X4 Classic buttons and X3 text. No implementation, release, firmware pin change or expansion of existing approval. All values are synthetic. These static scenes do not contact a server.

Scope, Android evidence and acceptance · Screen inventory · Approved firmware gallery

The 480 × 800 frames express design layout only. Firmware uses runtime dimensions and bezel-safe bounds; X3 uses bounded text without cover bitmaps. Touch targets are at least 50 design pixels. Button focus uses a black outline; Prev/Next move focus, Select activates, Back returns. Footer page arrows are focusable controls. No screen scrolls.

Counts are published totals with coverage, never the number of visible rows. On card opens verified local books. Your lists includes saved Smart scopes; the UI does not evaluate their rules.

NEEDS APPROVAL

Preserves every Android browse root. Unsupported roots are omitted by capability. Page navigation restores focus; it does not scroll.

NEEDS APPROVAL

Connectivity and snapshot freshness are independent. All saved indexes stay usable offline; entry starts no connection.

library-missing · Library

NEEDS APPROVAL

Unknown catalog counts stay unknown. Full refresh is explicit and uses its separately approved owner; no automatic radio boot or forced sign-in.

library-loading · Library

NEEDS APPROVAL

A bounded published-window request is pending. Paint performs no scan, transport or file work; Back retires this presentation.

library-error · Library

NEEDS APPROVAL

Keep the last valid window when available. Retry is an explicit Library intent. Authentication failure is not an empty catalog.

authors · Authors

NEEDS APPROVAL

Grouped book results, not a second author database. A partial group opens the same list scoped to that author. Complete groups show N books without an All link.

series-groups · Series

NEEDS APPROVAL

Contextual order and known progress come from Library. X4 shows saved progress dots; X3 uses state text. A named series header hands off to F36c; Not in a series opens a scoped list. No F36c detail or download-next screen is proposed here.

on-card · On card

NEEDS APPROVAL

Same shared list with On this device fixed. A missing file loses its local availability after service verification; a cached cover is not proof that a file exists.

lists · Your lists

NEEDS APPROVAL

Names and counts come from published opaque scope identities. No server list creation, editing or client-side Smart-scope evaluation.

scope · Short reads

NEEDS APPROVAL

Uses the selected opaque list identity with the shared list query. Back restores Your lists at its original page and focus.

list-page · All books

NEEDS APPROVAL

Whole rows and their metadata page together. Pro taps a row or page arrow; Classic/X3 Prev/Next focus controls and Select activates the page arrows. No scrolling.

list-back · Short reads

NEEDS APPROVAL

RETURN SCENE: Back from a user-opened panel restores this list, its page, filters and focused row (The Paper Coast). Back again returns to Your lists. Returning to the loaded reader preserves the exact position.

list-empty · Short reads

NEEDS APPROVAL

Zero is shown only for a known complete empty result. Resetting a filter does not remove books or change the saved server list.

list-missing · Short reads

NEEDS APPROVAL

Offline without data differs from an empty result. Retry asks Library for eligible work; it does not connect without consent.

list-incomplete · Series

NEEDS APPROVAL

Do not claim All N, complete counts or a bulk next action until membership coverage is known. Existing accessible rows remain usable.

list-error · Short reads

NEEDS APPROVAL

Preserve the previous good window, selection and cursor if one exists. Late errors cannot replace a departed list or appear over reading.

lists-unsupported · Your lists

NEEDS APPROVAL

A restored shortcut may show this explanation; unsupported roots are normally omitted. Unavailable is distinct from no lists and not saved yet.

download-options · Download

NEEDS APPROVAL

A Library-projected supported-file chooser precedes transfer when needed. File and destination identities stay private. Initial button focus is the first supported option; Cancel starts nothing.

download-offline · Not downloaded

NEEDS APPROVAL

Offline row selection opens this consent. Cancel/Back restores the exact originating row and starts no connection. Successful connection proceeds through the normal chooser.

download-preparing · Preparing download

NEEDS APPROVAL

User-requested progress only. Services validate identity and storage. Cancel is serviced when safe; leaving retires auto-open without discarding durable work.

download-progress · Downloading

NEEDS APPROVAL

Coarse progress; no animation. Duplicate selections deduplicate the job. Open on verified completion only if the initiating owner is still active. Back retires auto-open and restores the list.

download-unknown · Downloading

NEEDS APPROVAL

No invented percentage. The same job and ownership rules apply to transfers with unknown length.

download-failed · Download stopped

NEEDS APPROVAL

Explicit Resume uses the same job. Space, access and validation errors use service-projected reasons; nothing deletes an existing complete file or claims success.

download-canceled · Download canceled

NEEDS APPROVAL

Cancellation affects only this job. No automatic retry, open or removal of an existing complete file.

download-unsupported · Cannot download this book

NEEDS APPROVAL

No transfer starts. Local books remain openable. The presentation does not guess a format conversion or fetch detail during paint.

download-login · Download unavailable

NEEDS APPROVAL

Set up hands off to the separately approved Account owner. Cancel/Back leaves the list intact; no credentials or vendor protocol enter this UI.

download-space · Not enough space

NEEDS APPROVAL

Library owns the capacity check and safe reserve. Do not delete books, annotations or queued work to make room. No invented free-space figure.

download-access · Download unavailable

NEEDS APPROVAL

Authorization loss is not an empty catalog. Existing permitted local files remain accessible. Account changes retire this owner and all stale deliveries.

download-saved · On card

NEEDS APPROVAL

Return scene after the owner has declined auto-open or reopened job information. Open is explicit. A completion delivered after Back never reopens the departed list or reader.
