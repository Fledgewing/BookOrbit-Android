BookSync · 0.12.1 · APPROVED (2026-11-27)

Quiet bedtime and eye-rest reminders

Every view, word and interaction below APPROVED (2026-11-27). The maintainer explicitly approved this design and every mockup, including bedtime and Rest your eyes, on 2026-11-27 at approximately 21:40 PT ("All approved").

Static, self-contained e-ink review gallery. One set of words, four input profiles. Rev-16 serif headings, black/white controls, outlined focus and no animation. Frames use the approved 480 × 800 review viewport; physical display fit and Android density remain acceptance work.

Bedtime: Got it · 10 more minutes · Sleep. Eye rest: Done · Turn off. Nothing locks, closes a book automatically or blocks reading. No sound, wake timer or local PIN. Touch keyboards are docked at the screen bottom. Family examples are future-only.

Library owns values, scheduling and storage; UI draws immutable snapshots and sends intents. This gallery includes 33 shared states × four platforms, plus the Android companion information row.

Settings entry

Android: BookSync reader settings → Reminders. Firmware: Settings → Reminders. Local access requires no PIN.

APPROVED (2026-11-27) · empty

No reminders

Rest your eyes defaults Off/20 and has initial row focus. No bedtime reminders are saved. Back returns to Settings.

APPROVED (2026-11-27) · saved

Saved reminders: On and Off

Select a local row to edit. Its On/Off action is explicit in the editor; four rows per page at most.

APPROVED (2026-11-27) · unknown

Unknown clock

Same Library clock-unavailable state on all four renderers. Android is a synthetic fault state; firmware can reach it after cold boot. Adding/editing remains available.

APPROVED (2026-11-27) · add

Add reminder

New draft defaults: On, 9:00 PM, Every day, default message. Save alone persists. Back discards the draft.

APPROVED (2026-11-27) · edit

Edit reminder

The local On/Off row toggles the draft. Delete asks first; it is never the initial action.

APPROVED (2026-11-27) · off

Disabled reminder draft

On/Off changes only this local reminder. Save is required; no PIN.

APPROVED (2026-11-27) · time12

Time picker: 12-hour

Touch uses a numeric keypad docked at bottom. Button readers adjust digits and AM/PM; no touch keypad is assumed.

APPROVED (2026-11-27) · time24

Time picker: 24-hour

Device format changes labels only. No AM/PM control in 24-hour format.

APPROVED (2026-11-27) · days

Days presets

Done returns to the unsaved reminder draft. Custom days opens the seven-day list.

APPROVED (2026-11-27) · custom

Custom days

At least one day is required. Seven fixed choices fit one bounded list; focus is shown on Monday.

APPROVED (2026-11-27) · days-invalid

No custom day selected

Done is disabled until a day is chosen; the unsaved draft remains available.

APPROVED (2026-11-27) · message

Optional message

Touch keyboard is a direct screen child docked at bottom, with field and Done above. Buttons select letters; X3 keeps text focus. Keyboard Done returns to draft.

APPROVED (2026-11-27) · delete

Delete confirmation

Cancel has initial focus. Delete removes only this local schedule and its snooze after durable save.

APPROVED (2026-11-27) · full

Eight-reminder limit

One interval row plus three time rows shown. Add is disabled at eight time reminders; eye rest remains available. Never evict another reminder.

APPROVED (2026-11-27) · saving

Saving

One pending action, no spinner or animation. Back retires the view; durable work settles without reopening it.

APPROVED (2026-11-27) · save-error

Save failed

Draft and previous schedule survive; retry is explicit. Applies to full/read-only/missing storage.

APPROVED (2026-11-27) · recovered

Previous valid storage recovered

A Settings-only explanation; never a background error over a book.

APPROVED (2026-11-27) · unreadable

No valid storage

Keep damaged bytes and fire no reminders. Retry rereads through Library; Back always works.

APPROVED (2026-11-27) · in-book

Reminder over the page

Approved exception, proposed presentation APPROVED (2026-11-27). Got it is initial focus. Back/page turn/outside tap dismiss safely. Only a fresh explicit Sleep selection sleeps.

APPROVED (2026-11-27) · missed

Missed reminder

Same sheet once on visible return within 60 minutes. It names the original due time. No wake timer.

APPROVED (2026-11-27) · home

Due on Home or a menu

Same words and actions over the current non-reading view. A menu uses this same sheet and returns to that menu.

APPROVED (2026-11-27) · sleep-unavailable

Sleep unavailable

No permission prompt or helper activation. Got it and snooze remain usable; Sleep is disabled. This commonly matters on Android without its existing sleep permission.

APPROVED (2026-11-27) · sleep-error

Explicit Sleep failed

Only after the reader chooses Sleep. Keep the page open; restore Got it focus. Retry Sleep is explicit.

APPROVED (2026-11-27) · eye-off

Rest your eyes: Off by default

One device-local interval setting, separate from the eight bedtime slots. No PIN. Select the row to edit.

APPROVED (2026-11-27) · eye-on

Rest your eyes: On

Same setting when enabled. Time counts only while a book page is in use; five minutes away resets the count.

APPROVED (2026-11-27) · eye-edit

Rest your eyes: Settings

On/Off and Interval only. Default Off/20. Save persists through Library; Back discards the draft. No add/delete, time-of-day, days or custom message.

APPROVED (2026-11-27) · eye-interval

Eye-rest interval picker

20 minutes is the default. Select 20, 30, 45 or 60; Done returns to the unsaved editor draft. No keyboard is needed.

APPROVED (2026-11-27) · eye-sheet

Rest your eyes over the page

Done is initial focus. Back/page turn/outside tap acts as Done. Turn off requires a fresh explicit selection. Static text: no countdown, timed close or extra e-ink refreshes. Bedtime wins when both become due together.

APPROVED (2026-11-27) · eye-error

Turn off failed

After explicit Turn off only. Keep the setting enabled and retain Done focus; retry is explicit. No automatic error popup or redraw.

APPROVED (2026-11-27) · eye-managed

Future managed eye-rest sheet

Future: not built in 0.12.1. Same source rule as time reminders: Done dismisses, Turn off is disabled and the service rejects local mutation.

APPROVED (2026-11-27) · Android companion only

Companion settings: discoverability

Reading and Home gains one information row, also found by reminder/bedtime search. No second editor and no automatic app switch. Local reminder information and the reader route are accessible without PIN.
