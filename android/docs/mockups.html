Meebook M8C sync with BookOrbit: mockups, revision 2

Draft for approval; nothing is built. Screens are drawn at the M8C's 3:4 portrait ratio (1404 x 1872, Android 14: spec-site figures, not yet checked on the device). The official BookOrbit KOReader plugin does every pull and push and holds the only copy of the login. The "orbit-android" KOReader patch only gets the network ready and tells the plugin when to sync. "BookSync Companion" (one APK: launcher + background service) only switches Wi-Fi, wakes Tailscale, holds a wake lock and turns the screen off. It never talks to BookOrbit.
